# Входные данные

Исходные данные — сообщения реальных клиентов, поэтому в репозиторий они не входят. Для запуска положите в эту папку два файла.

## `messages.csv`

Уникальные сообщения клиентов с частотой.

| Колонка | Описание |
|---|---|
| `text_id` | идентификатор сообщения |
| `text_clean` | очищенный текст: нижний регистр, без пунктуации, персональные данные замаскированы |
| `freq` | сколько раз сообщение встречалось в выборке |

```csv
text_id,text_clean,freq
1,хочу открыть расчетный счет,120
2,мне нужен эквайринг,85
3,свяжите с оператором,64
```

Пустые сообщения и сообщения короче 5 символов отбрасываются при загрузке.

## `intents.txt`

Примеры фраз из существующих интентов чат-бота, по одной в строке. Используются на шаге фильтрации, чтобы отсеять сообщения, похожие на то, что в интентах уже есть.

```text
открыть счет для бизнеса
хочу открыть расчетный счет для ип
как открыть счет для ооо
```
